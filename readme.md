# FidoFido

It is a django-powered project now!

## Initialization

Please run the following command for valid:

```bash
# Having some questions? Submit an issue.

# Step 1
django-admin version # Check if Django exists, if you have installed Django, it will print the current version of Django
pip install django # If you haven't installed Django

# Step 2
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser # This command will ask you entering username, email and password.
python manage.py runserver
```
